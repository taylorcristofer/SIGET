# SIGET — Sistema de Gestão de Terceirizados

## 📌 Sobre o Projeto

O SIGET (Sistema de Gestão de Terceirizados) é um sistema web desenvolvido com foco na organização e gerenciamento operacional de empresas prestadoras de serviços terceirizados.

O projeto foi idealizado para atender uma empresa real do segmento de terceirização de mão de obra, responsável pela alocação de profissionais como:

* ASG
* Garçom
* Copeira
* Manutenção
* Serviços gerais

O sistema busca centralizar e otimizar processos administrativos que atualmente são realizados manualmente.

---

## 🎯 Objetivos do Sistema

* Gerenciar funcionários terceirizados;
* Controlar alocações em órgãos públicos;
* Centralizar informações operacionais;
* Melhorar a organização administrativa;
* Reduzir processos manuais;
* Facilitar o acompanhamento de contratos e escalas.

## 🏗️ Arquitetura do Projeto

O sistema segue arquitetura em camadas:

```text

```

### Backend

* Java
* Spring Boot
* API REST
* Spring Security
* JPA / Hibernate

### Banco de Dados

* PostgreSQL
